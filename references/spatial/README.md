# Spatial references

Den här mappen innehåller bindande maskinläsbara spatiala modeller för UBRF.

Aktiv modell för omtvistade interiörer: `UBRF-SPATIAL-CANON-v2.json`.

Princip: fysisk geometri modelleras som `WALL`, `OPENING`, `GLASS`, `OPEN_AREA` och `NO_WALL_ZONE`. Rumsnamn är metadata och får inte skapa väggar.

Vid konflikt med aktuell implementation vinner Product Owner-korrigering + aktiv Spatial Canon enligt `docs/SPATIAL-CANON-V2.md`.
